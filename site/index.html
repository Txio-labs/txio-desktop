Download

Pick the installer for your computer.

Linux

Debian, Ubuntu, Kali, Fedora, openSUSE and others, or any distribution with the AppImage.

Or install from the terminal (any distribution); your package manager then keeps it up to date:

curl -fsSL https://txio-labs.github.io/txio-desktop/install.sh | sudo sh

macOS

Apple silicon and Intel. macOS 11 or later.

First launch: right-click Txio in Applications and choose Open.

Or with Homebrew:

brew tap txio-labs/txio https://github.com/Txio-labs/txio-desktop
brew install --cask txio

Windows

Windows 10 and 11, 64-bit.

If SmartScreen warns you, choose More info, then Run anyway.

Or with Scoop:

scoop bucket add txio https://github.com/Txio-labs/txio-desktop
scoop install txio

Already installed? Txio updates itself: new versions download in the background and you restart when it suits you.
